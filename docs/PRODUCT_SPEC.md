# 小尘课簿产品规格（V1）

小尘课簿是一款面向教师的离线课时记录工具。核心流程是：打开当前月份日历，点击日期，快速记录授课节数、晚辅节数和可选备注。数据保存在本地 Room，不需要账号、网络或广告。

## 一级导航

底部仅包含：日历、统计、设置。历史记录从统计页面进入二级页面。

## 数据规则

- 每天最多一条 TeachingRecord；相同日期使用 Upsert。
- `lessonCount` 与 `eveningSupportCount` 不得小于 0。
- 两个计数均为 0 且备注为空时删除记录。
- Semester 仅通过日期范围动态归属记录；删除学期不会删除课时记录。
- 累计统计全部由原始记录动态计算，不保存冗余总数。

## 备份

JSON 备份包含 schemaVersion、记录、学期和 Quick Presets；CSV 包含日期、星期、授课、晚辅、备注和所属学期。文件通过 Storage Access Framework 由用户选择位置。
